# Zomato Restaurant Data Analysis

## Project Overview

This project analyzes restaurant data to understand customer preferences, restaurant popularity, pricing patterns, and the impact of online ordering on ratings.

## Objective

The objective of this project is to perform exploratory data analysis (EDA) on restaurant data and generate business insights that can support data-driven decision-making in the food service industry.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Data cleaning and preprocessing
* Handling missing values
* Converting ratings and cost columns to numeric format
* Identifying popular restaurant categories
* Analyzing customer votes by restaurant type
* Evaluating online order availability
* Exploring restaurant rating distributions
* Analyzing approximate cost for two people
* Comparing ratings for online and offline orders

## Key Insights

* Casual Dining and Quick Bites are among the most common restaurant categories.
* Restaurants offering online ordering tend to have higher customer ratings.
* Customer engagement varies significantly across restaurant categories.
* Most restaurants fall within a moderate price range for couples.
